题库 / P1042

区间最值查询（RMQ）

黄金
题目描述

给定一个长度为 n 的整数序列 a₁, a₂, …, aₙ，以及 q 次询问。每次询问给出区间 [l, r]，你需要回答该区间内的最大值。

序列元素在两次询问之间不会发生变化。为了获得满分，请设计一个 O((n + q) log n) 或更优的算法。

输入格式

第一行两个整数 n, q（1 ≤ n, q ≤ 2×10⁵）。
第二行 n 个整数，第 i 个表示 aᵢ（|aᵢ| ≤ 10⁹）。
接下来 q 行，每行两个整数 l, r（1 ≤ l ≤ r ≤ n）。

输出格式

对每次询问输出一行一个整数，表示区间最大值。

样例
样例输入 #1
5 3
1 -2 7 5 -9
2 4
1 5
3 3
样例输出 #1
7
7
7
